
# TTA Corruption Robustness

Test-Time Adaptation for Corrupted Image Classification using CIFAR-10-C.

## Project Goal

This project investigates the robustness of Test-Time Adaptation (TTA)
methods under distribution shifts caused by common image corruptions.

Main method:
- TENT (Test-Time Entropy Minimization)

Datasets:
- CIFAR-10
- CIFAR-10-C

Models:
- ResNet-18
- Simple CNN

Experiments:
- Frozen baseline evaluation
- TENT adaptation
- Corruption severity analysis
- Adaptation stability analysis
- Order sensitivity analysis
